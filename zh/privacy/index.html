计算数据

你输入的日期、时间、活动名称和时长均在浏览器本地处理，网站不会把这些计算内容发送到服务器。

本地保存与分享

当你主动保存高级计划或选择主题时，相关内容会写入本机浏览器的 localStorage。分享计划时，计划内容会编码在链接的 hash（“#”之后）中，通常不会随网页请求发送给服务器；收到链接的人可以读取其中的计划。你可以清除浏览器网站数据来删除本地保存内容。

访问分析

我们使用 Cloudflare Web Analytics 了解总体访问量和网站性能。它可能提供访问、页面浏览、来源网站、大致国家或地区、设备与浏览器类型等汇总信息。该服务不使用 Cookie 或 localStorage 进行这些测量，也不会收集你输入的计算内容。

广告

网站当前没有启用真实广告代码。如果今后启用广告或其他需要同意的技术，我们会更新本页，并在适用法律要求时提供接受、拒绝或管理同意的控制。

外部服务

网站交付和汇总分析由 Cloudflare 提供。你可以查看 Cloudflare 隐私政策。

政策更新

网站功能或法律要求变化时，本政策可能更新，最新日期会显示在本页顶部。
